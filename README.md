# ASTREA v1.2.0

ASTREA is a roguelike game built with Python and Pygame.

## Download

Get the build for your device from [GitHub Releases](https://github.com/CookieG256/ASTREA/releases):

- **Android phone:** [Download ASTREA-Android.apk](https://github.com/CookieG256/ASTREA/releases/download/v1.2.0/ASTREA-Android.apk)
- **Windows, macOS, or Linux:** choose the package matching your system in the release.

On Android, download the APK, open it, and allow installation from your browser or file manager if Android asks. The Android build includes on-screen touch controls; the desktop builds do not show them.

## Features

- Playable on Android, Windows, macOS, and Linux.
- Touch controls on mobile and keyboard/controller support on desktop.
- Multiple races, classes, weapons, enemies, biomes, and local co-op.
- Enemy sprite animations loaded from the included sprite library.
